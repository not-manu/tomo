Welcome to your
shared computer.

This desktop is one real machine that your whole team — and its AI agents — use at the same time. Everything you open, type and run here, everyone else sees live. It's still here after you all log off.

M C
tomo is better with friends.

Alone, it's a nice cloud computer. With a teammate, it's one screen with two mice. Click Invite at the top of the desktop (or Members in the lobby), add an email, and watch their cursor show up.

Things to try

01 Open the Terminal

It's in the dock. A real Linux shell with Python, Node and git — and everyone in the room sees the same one.

02 Put an agent to work

Type codex in the terminal and ask for something. It edits the same files you're looking at, in front of everyone.

03 Drop in files

Drag anything from your computer into Finder. It's instantly on everyone's screen. Right-click to download or delete.

04 Edit together

Double-click a text or code file. Two people can type in it at once, like a shared doc.

05 Run a web app

Start a dev server, e.g. npx create-vite app, then open the Browser app on 5173. Share the link with anyone.

06 Make more room

Add desktops with the tabs up top. Leave whenever — windows, files and running programs stay put.
